# Milestone 3: Counter, Weight Tools, and Workout UX

## Goals
- Add touch-friendly rep counting.
- Provide predefined weight selection and conversion tool.
- Improve the per-round data-entry experience for fast tracking while following a workout video.

## Deliverables
- Tap-to-count interaction
- Weight selector with 1, 3, 5, 8, and 10 kg values
- lb/kg converter
- Edit and corrections for a round's rep or weight values
- Quick transition between rounds and exercises in the active workout

## Scope
- Counter UX
- Round-level measurement entry
- Metric conversion
- Validation of saved values

## Exit criteria
- User can add reps with taps and fix mistakes easily.
- Weight values are consistent and selectable from the required set.
- Every completed round is attached to the correct exercise inside the active workout.
- Logging flow is fast enough for daily training use.
